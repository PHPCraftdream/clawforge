Итоговая архитектура (после последнего уточнения пользователя): **фреймворк** в
`tools/framework/` содержит весь код, включая предметные команды (`bootstrap`, `backup`,
`pull`/`push`, `verify`, `secrets`, `recipe`, `deploy`, `smoke`), а **развёртывание** —
это каталог `apps/<имя>/` с `.env`, `config/desired-state.json`, `secrets/`, `recipes/` и
короткой декларацией `app.ts`. Точка входа `./clawforge` — гейт: выбирает развёртывание
(`--app` / `OC_APP`, по умолчанию `openclaw2`), указывает фреймворку его каталог и
передаёт управление. Все пути конфигурации разрешаются от каталога развёртывания, иначе
два инстанса молча делили бы одни ключи.

Ключевые механизмы: транспорт (local / wsl / ssh) — код может исполняться на Windows-Node
и доставать до цели через `wsl.exe`; мост путей переводит между четырьмя системами
координат (наша сторона, цель, контейнер, удалённый сервер) и покрыт 48 табличными
проверками; контракт рантайма прячет Docker; снапшоты состояния имеют три профиля

## Decisions

- Приложение = каталог развёртывания (конфиги, секреты, снапшоты) + декларация, а не
  кодовая база. Отвергнут предыдущий вариант, где предметные команды считались частью
  приложения: команды переиспользуемы между развёртываниями одного сервиса.
- `docker-compose.yml` остаётся общим во фреймворке; различается только project-directory,
  которую получает compose — оттуда он читает `.env` конкретного развёртывания. Отвергнуто
  копирование compose в каждое развёртывание.
- Полный переход обвязки на TypeScript вместо bash. Node исполняет TS напрямую (type
  stripping), поэтому нет ни сборки, ни `tsx`, ни `node_modules`; цена — недоступны
  конструкции с кодогенерацией (`constructor(private x)`, `enum`, декораторы).
- Node на хосте не устанавливаем сами: зависимости — ответственность пользователя, `./clawforge`
  только проверяет и сообщает, чего не хватает. Отвергнута автоустановка через NodeSource.
- Рантайм — только Docker; настройки `bare` нет, но контракт оставляет для неё место, и в
  командах нет ни одного упоминания docker (проверяется грепом).
