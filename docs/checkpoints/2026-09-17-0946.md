## Decisions

- Chose to REPORT the Windows/WSL boundary rather than enforce it (#237): a credential file on
  an automounted drive is reachable by any Linux user, but refusing would stop every deployment
  on a Windows drive — the primary documented configuration — and left `init` half-finished.
  The review allowed either refusing or diagnosing.
- Chose `icacls` "drop inheritance, remove each foreign trustee, grant the closed SID set" in
  one invocation over the reviewer's suggested `/restore` (#242): `/restore` is
  privilege-blocked for a non-elevated user on this machine; the reason is recorded in the code.
- Chose to publish the tarball `verify` built, passed as a workflow artifact, over installing
  dev dependencies in each publish job (#235): the bytes that reach the registry are then the
  ones that were checked, and `npm publish <tgz>` runs no prepack at all.
- Chose one `/wrush` agent rather than several for the file split: all the work touched one
  directory and one check file, and parallel agents on the same files corrupt each other.
- Chose to scope the "split everything over 700 lines" work to `clawforge` alone, and to keep
  the 7-entry rule limited to directories that contain source files — both confirmed by the
  user when the scope turned out to span ~25 repositories otherwise.
