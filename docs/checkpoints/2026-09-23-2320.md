- Разбил накопленный diff на 7 коммитов по подсистемам вместо одного гигантского коммита —
  прецедент репозитория (be7a701 объединял rounds 2-3 в один коммит) допускает и то, и другое;
  выбрана более гранулярная схема по явной просьбе "сделай коммиты" (множественное число).
  Порядок коммитов подобран по зависимостям (recipe.ts→recipe/index.ts rename — первым среди
  зависимых), но promitted: intermediate-коммиты НЕ проверялись typecheck'ом по отдельности,
  только финальное состояние.
- Каждый CI-баг чинился через цикл diagnostic→push→read-log→fix-for-real, поскольку локальная
  среда (WSL, uid=1000-эквивалент) систематически маскирует ровно те privilege/identity-баги,
  которые проявляются только на реальном CI runner'е с другим uid и другой Windows-версией.
- По явной команде пользователя — прекратил охоту за седьмым (Windows-only,
  inspect/checksums.ts) багом, не связанным с round 6/7, задокументировал вместо продолжения
  вслепую через push-итерации.
- Round-7 декомпозирован на 11 задач (не 17 — по одной на finding), кластеризовано по
  пересечению файлов, тем же паттерном что round 6's 18-из-24.
