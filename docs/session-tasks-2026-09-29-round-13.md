# Сессионные задачи: ревью раунда 13

Основание: [статическое ревью XS, раунд 13](review-2026-09-29-xs-round-13.md).

| Задача | Приоритет | Статус |
| --- | --- | --- |
| R13-01: ограничить `rsync --delete` проверенным деревом | P1 | закрыта: receiver запускается из проверенного каталога |
| R13-02: исключить локальные worktree и зависимости из deploy | P2 | закрыта: framework и recipes используют разные правила исключений |
| R13-03: проверять remote root до `mkdir`/`chown` | P2 | закрыта: компоненты проверяются до записи |

Дополнительно закрыты найденные при консультации XXA случаи: marker создаётся
исключительно без следования ссылке, а все вызовы rsync фиксируют режим аргументов.
Конкурирующий процесс, который сам может переставлять каталоги на удалённом
хосте во время deploy, остаётся за пределами гарантии обычного rsync.

После интеграции прошли 172 check-файла; три пропущены из-за возможностей среды
(`gnu-userland`, `linux-host`, `ssh-loopback`). Прошли typecheck, Oxlint,
сборка, pack dry-run и actionlint. Исправления фиксируются отдельным локальным
коммитом до следующего ревью.
